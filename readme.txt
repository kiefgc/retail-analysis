RETAIL CUSTOMER INTELLIGENCE APP

This is an interactive web application that analyzes customer data to generate insights about customer behavior, predicted spending, and marketing effectiveness.

The app is designed to help businesses understand their customers better and make smarter decisions about promotions and engagement strategies.

---

WHAT THE APP DOES

This application allows you to:

• Identify what type of customer someone is (Customer Segment)
• Predict whether a customer will respond to a promotion
• Estimate a customer’s spending behavior
• Analyze multiple customers at once using a CSV file
• View performance of different machine learning models

---

FEATURES

1. Single Customer Prediction
   Enter a customer’s information and instantly get:

   * Customer segment (e.g., High Value, Inactive, etc.)
   * Promotion response prediction (Yes/No)
   * Spending score
   * Recommended business action

2. Batch Analysis
   Upload a CSV file of customers and:

   * Run predictions for all customers
   * View summaries and charts
   * Download the results

3. Model Performance
   View a summary of how different models perform in terms of accuracy and effectiveness.

---

HOW TO USE THE APP

1. Open the app (see instructions below)
2. Choose a page from the sidebar:

   * Single Customer → for individual predictions
   * Batch Analysis → for CSV uploads
   * Model Performance → for model insights
3. Input data or upload a file
4. Click the “Run Prediction” button
5. View results and insights on screen
